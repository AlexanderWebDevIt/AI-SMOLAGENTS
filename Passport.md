# Passport: AI-Agent System

## 🎯 Назначение проекта
Это интеллектуальный агентный фреймворк, предназначенный для решения сложных задач с использованием внешних знаний и программного выполнения кода. В отличие от простых чат-ботов, этот агент обладает способностью "размышлять", использовать инструменты (tools) и работать с контекстом через механизмы памяти и RAG.

## 🚀 Ключевые возможности (Capabilities)

### 🧠 Интеллектуальный цикл (Agent Loop)
Агент работает по циклу "Вопрос $\rightarrow$ Мысль $\rightarrow$ Действие $\rightarrow$ Наблюдение $\rightarrow$ Ответ". Он способен планировать шаги для решения многоступенчатых задач, исходя из предоставленной инструкции.

### 📚 RAG (Retrieval-Augmented Generation)
Интегрированная система работы с неструктурированными данными.
* **Технологии:** ChromaDB, LangChain.
* **Функция:** Позволяет агенту "читать" загруженные документы и отвечать на вопросы, основываясь на их фактическом содержании, что значительно снижает риск галлюцинаций LLM.

### 💾 Долгосрочная память (Memory)
Система управления контекстом диалога.
* **Технологии:** SQLite.
* **Функция:** Сохраняет историю сессий, позволяя агенту "помнить" детали разговора и поддерживать связность диалога между разными запросами.

### 💻 Песочница кода (Code Sandbox)
Механизм для выполнения программного кода в изолированной среде.
* **Механизм:** Запуск через `subprocess`.
* **Функция:** Агент может самостоятельно писать и выполнять Python-скрипты для выполнения точных математических вычислений, обработки данных или решения алгоритмических задач.

## 🛠 Технологический стек

| Уровень | Технология |
| :--- | :--- |
| **Backend** | Python 3.11+, FastAPI |
| **Frontend** | React (Vite) |
| **Векторная БД** | ChromaDB |
| **Оркестрация RAG** | LangChain |
| **База данных** | SQLite |
| **LLM Interface** | OpenAI-compatible API (OpenAI, Ollama, LM Studio) |

## 🏗 Архитектура приложения

```text
backend/
├── app/
│   ├── agent/     # Логика принятия решений и планирования (Agent Loop)
│   ├── rag/       # Поиск и извлечение информации из документов (RAG Engine)
│   ├── memory/    # Управление историей диалогов и сессиями (Memory Store)
│   └── sandbox/   # Изолированное выполнение кода (Code Execution)
└── main.py        # API интерфейс (FastAPI Entry Point)
```

## 💡 Примеры использования
1. **Работа с базой знаний:** "Проанализируй загруженные отчеты и скажи, как изменилась прибыль за квартал".
2. **Сложные вычисления:** "Вычисли корень из суммы всех чисел в списке [12, 45, 7, 23] и выведи результат".
3. **Диалоговое взаимодействие:** "Вспомни, о чем мы говорили в прошлый раз, и предложи идеи для развития этой темы".
